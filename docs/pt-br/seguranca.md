# Política de Segurança

🌐 **Idioma:** [English](../../SECURITY.md) · Português

## Versões suportadas

`oito2_foundation` e `oito2_settings` são publicados juntos, com uma única versão. Antes da 1.0, só a linha minor mais recente recebe correções de segurança.

| Versão | Suportada |
| ------ | --------- |
| 0.1.x  | ✅        |

## Como reportar uma vulnerabilidade

Reporte vulnerabilidades **de forma privada**, nunca por uma issue, pull request ou discussão pública.

Use o reporte privado de vulnerabilidades do GitHub: abra a [aba **Security**](https://github.com/oito2/oito2_rs/security) do repositório e escolha **Report a vulnerability**.

## O que incluir

- O crate afetado (`oito2_foundation` ou `oito2_settings`) e a versão.
- O sistema operacional e, no Linux, o ambiente de desktop.
- Os passos para reproduzir, uma prova de conceito se você tiver, e o impacto esperado.

## O que esperar

Os mantenedores confirmam o recebimento no mesmo advisory privado, investigam e mantêm você informado por lá. Quando a correção fica pronta, ela é publicada em uma nova versão e o advisory é tornado público, com crédito a você, a menos que prefira ficar anônimo.
